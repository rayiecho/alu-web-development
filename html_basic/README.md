# HTML, basic

A small two-page website built with plain HTML only.

| File | Description |
|------|-------------|
| base_index.html | Minimal valid HTML page: DOCTYPE, head with charset and title, empty body |
| index.html | Homepage with headings (h1–h3), paragraphs, a clickable image and a link to tweets.html |
| tweets.html | Page with an embedded tweet and a link back to index.html |

Both `index.html` and `tweets.html` share the same structure: a `<header>` with a navigation list, a `<main>` holding an `<article>` and an `<aside>`, and a `<footer>`.
